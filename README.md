# Telegram Verification Bot

Бот для автоматической проверки возраста пользователей перед допуском в Telegram-группу.

## Структура проекта

```
.
├── bot.py                 # Точка входа
├── config.py              # Конфигурация
├── database/
│   ├── __init__.py
│   └── db.py              # Работа с SQLite
├── handlers/
│   ├── __init__.py
│   ├── group.py           # Обработчики группы
│   ├── private.py         # Обработчики ЛС (верификация)
│   └── admin.py           # Админские команды
├── keyboards/
│   ├── __init__.py
│   └── inline.py          # Inline клавиатуры
├── middlewares/
│   ├── __init__.py
│   └── admin.py           # Middleware для проверки админов
├── services/
│   ├── __init__.py
│   └── notification.py    # Уведомления админам
├── states/
│   ├── __init__.py
│   └── verification.py    # FSM состояния
├── .env                   # Переменные окружения
├── .env.example           # Пример .env

└── README.md              # Этот файл
```

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository_url>
cd <project_directory>
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Заполните `.env` своими данными:
```
BOT_TOKEN=your_bot_token_here
GROUP_ID=-1001234567890
```

5. Запустите бота:
```bash
python bot.py
```

## Настройка

### Переменные окружения

| Переменная | Описание |
|------------|----------|
| `BOT_TOKEN` | Токен вашего бота от @BotFather |
| `GROUP_ID` | ID группы, где бот будет проверять пользователей |

### Настройка админов

Откройте `config.py` и измените список админов:

```python
ADMINS = {123456789, 987654321}  # Замените на ваши Telegram ID
```

## Команды для админов

Все команды работают **только в личных сообщениях** с ботом:

| Команда | Описание |
|---------|----------|
| `/pending` | Показать список необработанных заявок |
| `/review <id>` | Показать заявку для модерации |
| `/approve <id>` | Одобрить заявку |
| `/reject <id> <reason>` | Отклонить заявку с указанием причины |
| `/stats` | Показать статистику по заявкам |

## Как это работает

1. Новый пользователь вступает в группу
2. Бот ограничивает права пользователя (не может писать, отправлять медиа)
3. Бот отправляет сообщение с кнопкой "Пройти проверку"
4. Пользователь переходит в ЛС и нажимает "Мне есть 18 лет"
5. Пользователь отправляет фото документа (с замазанными личными данными)
6. Пользователь отправляет video note (кружок)
7. Заявка отправляется админам
8. Админ рассматривает заявку и принимает решение

## Требования к документу

Пользователь должен замазать:
- Номер документа
- Серию документа
- Адрес
- Подпись

Должны остаться видимыми:
- Лицо (фотография)
- Дата рождения

## Автоматический кик

Если пользователь не начал проверку в течение 30 минут после вступления в группу, он будет автоматически удалён из группы.

## Логи

Логи выводятся в консоль и сохраняются в файл `bot.log`.
